      What this lab demonstrates

      Three configuration scenarios and a one-turn limit are real SDK experiments. Managed policy, inline settings, other models, MCP, subagents, skills, structured output, persistence, checkpoints and sandboxing are reference topics in the feature map, not implemented integrations. The path hook and fixed directory are application guards, not an operating-system sandbox.

      maxBudgetUsd is an SDK estimate threshold, not an exact invoice guarantee. maxTurns is a runtime turn limit, not a message counter. The host also has a timeout. Results remain actual outcomes; no saved model answer substitutes for a failed run.
