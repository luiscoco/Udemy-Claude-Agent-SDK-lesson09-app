01

Compose one options object

Set a model, fixed working directory, available tools, pre-approvals and limits before query(). Omitted fields use SDK defaults; this lab makes its relevant choices explicit.

02

Separate three configuration sources

Inspect programmatic options, a real project settings file and a safe environment projection. The live host spreads process.env while keeping inherited secrets out of the UI.

03

Understand configuration precedence

Managed policy ranks above application configuration. Local, project and user files have their own order. The experiment demonstrates a project Edit allow versus an explicit programmatic block.

04

Distinguish tools from allowedTools

tools defines availability; allowedTools pre-approves calls. An unlisted Edit remains available in the approval experiment and reaches canUseTool.

05

Observe a real callback decision

The host automatically approves only Edit on its private status.txt in the controlled experiment. This is an actual callback, not a simulated user approval or an unrestricted editing agent.

06

Bound and inspect a run

Choose a turn limit, an SDK spend threshold and effort. Preserve actual typed results, including error_max_turns. Sampling parameters such as temperature are not SDK options.

This is the lesson's general source hierarchy. Individual features have evaluation rules. Permission deny rules still matter: the implemented experiment loads a project allow but removes Edit programmatically. It does not test managed policy or claim an application allow can bypass a policy or deny rule.

Your three exercises

  1. Run the read-only TODO summary. Confirm the IDs and that status.txt stayed unchanged.
  2. Run the only-Read-pre-approved experiment. Observe Edit in init, the actual callback decision and the changed file.
  3. Run the project-allow/programmatic-block experiment. Compare the settings file, disallowedTools, init availability and unchanged status.

Then repeat the summary with maxTurns set to 1 and inspect the actual error result.
